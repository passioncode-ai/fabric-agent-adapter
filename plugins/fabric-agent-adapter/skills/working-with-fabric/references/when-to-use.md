# When to use working-with-fabric

The skill's full trigger description, kept here so the front matter's `description` stays within the client's skill listing budget (about 350 characters a skill). Read it when choosing between this skill and a neighbour.

Use when a coding agent (Claude Code, Codex, Kimi Code, Kilo, Hermes) works in a project through Fabric: finding Fabric, having the lifecycle broker start Fabric, registering fabric-mcp once with no secret, fabric_whoami first, the project board (com.status, com.list, com.read_ack, com.submit to another Project, watch-mail), claiming and releasing work (fabric_work_claim, fabric_work_release), relaying the operator's decision or mandate (operator-decision-required), reports, handoffs, refusals. Triggers: "connect to Fabric", "register fabric-mcp", "claim the task in Fabric", "check the project board", "ask the other project through Fabric", "Fabric is not running", «подключись к Fabric», «возьми задачу в Fabric», «проверь доску проекта», «Fabric не запущен», "hit your limit, resets at". Explains the plugin's session hooks. NOT for building or adapting an agent or a board responder (creating-fabric-agents, adapting-projects-to-fabric, building-fabric-services), changing Fabric's own code, or messaging people.
