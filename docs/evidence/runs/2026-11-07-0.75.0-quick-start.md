# 0.75.0: the README quick start with a real client

The README's "Quick start → MCP" run as written on the published package: `npm pack @passioncode-ai/fabric-agent-adapter@0.75.0`
into a throwaway folder, `KIT` pointing at its `building-fabric-services/scripts`. The sample served on port 47190, was
registered with `register`, probed with `check_service.py` (exit 0, so the `&&` wrote the client config), and called
from Claude Code with `--strict-mcp-config` and a temporary config holding the token in a header. Temporary paths are
written `<tmp>`.

## Output

