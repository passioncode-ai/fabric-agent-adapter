## Decisions (the grill, closed from the sources)

1. **Scope = what the repin forces.** Tightenings in the range that touch what the kits do now are in; additive surfaces
   are their own rows: `lifecycle.manager` `node`/`person` and a missing origin (FAA-34), OpenRouter attribution and the
   usage-report amendments (FAA-33), feed `data` (FAA-35), consumer agent (FAA-36), `protocols` (FAA-37).
2. **The Windows token-file reader is in scope.** First recorded as "no reader in the kits"; that was wrong — both
   kits read their own token file and `check_service.py` reads a descriptor's ACL (`token_acl_problem`), and the
   contract's CT-18 row names it. Ported as `windows_token_acl_problem` / `windowsTokenAclProblem` with
   `windows-token.json`; the readers now hand it every ACE's type and mask (REQ-13).
3. **The marker reader** is `supervisor_marker(env, argv)` / `supervisorMarker({env, argv})`, a port of the contract's
   function with its verdict shape; `supervised()` keeps its name and answers `kind == "supervised"`. A conflict exits 75
   before the lock, naming both forms present.
4. **`hub_key_certified` / `hubKeyCertified`** take the contract's signature and answer its verdict (a breaking change
   from 0.21.0's boolean, which DEC-0060 *Compatibility* (j) names). The delegation verifiers take `estate`,
   `estateApplied`, `estateRevocations`.
5. **Vectors are generated, never written**: `estate-vectors.json` regenerated; `hub-key.json` and
   `service-supervisor.json` vendored byte for byte from `fe55fc6` with the private seeds dropped where present.
6. **Version 0.23.0** (minor: the kits' API changes; 0.22.0 went to FAA-12a, released first). Supported revisions keep
   `b291bf0`.
7. **Moved to FAA-34**, not done here: DEC-0061's `installedBy {by, role?, tool}`, `runner.credentialKind`, `peer`, and
   `lifecycle.manager: node` in the descriptor (with `label`/`plist` refused beside it), which CT-18 lists beside
   DEC-0069. The Windows CI receipt of whether the Task Scheduler restarts a task whose action exits 75 is a carry-over
   row.
