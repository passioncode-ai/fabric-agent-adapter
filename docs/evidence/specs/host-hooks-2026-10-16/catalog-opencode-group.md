# Additional host hook contract research

As of 2026-10-16. Read-only research; these rows do not assert an implemented adapter, installation, or Fabric admission. The local Switchboard catalogue supplied names and primary-source entry points, not hook acceptance. No additional host, model or provider was installed or selected.

| Host | Local observation | Verified primary-source contract | Adapter status / next boundary |
|---|---|---|---|
| Kilo CLI | Executable found; installed `@kilocode/cli/package.json` version `7.4.17` | Official plugin docs expose `experimental.chat.system.transform` over a system array; plugins in `~/.config/kilo/plugin/` and `.kilo/plugin/`. Current example exports `{id, server: factory}`. [Plugin reference](https://kilo.ai/docs/automate/extending/plugins). | Native contract candidate exists; **not implemented or native-probed**. Do not install the OpenCode shim into Kilo merely because both expose similarly named hooks; pin the installed Kilo contract and its loader first. |
| Zed Agent | `zed` absent from PATH; `/Applications/Zed.app` absent | Zed Agent reads personal `~/.config/zed/AGENTS.md` and project instruction files; external/terminal agents follow their own loaders. [Instructions](https://zed.dev/docs/ai/instructions), [agent surfaces](https://zed.dev/docs/ai/agents). | **No executable session-start context hook established** from these sources. Static instructions are a different capability; do not label ACP/MCP or instruction-file support as hooks. |
| Tabby (TabbyML/tabby) | `tabby` absent from PATH; no matching agent row in the inspected catalogue | Identity confirmed as the self-hosted AI coding assistant/inference and completion server with an OpenAPI interface, IDE clients and indexed context providers. [Official repository](https://github.com/TabbyML/tabby), [overview](https://tabby.tabbyml.com/docs/welcome/), [client configuration](https://tabby.tabbyml.com/docs/extensions/configurations/), [context providers](https://tabby.tabbyml.com/docs/administration/context/). | **No native session-start hook established** in this server/client contract. Server APIs and indexed context are different from an interactive agent's lifecycle hooks. No adapter or unsupported universal hook file created. |
| OMP / oh-my-pi | `omp` absent from PATH | Extension `before_agent_start` supports prompt overrides/custom messages. It can rerun during queued work or a changed prompt base; handlers must tolerate re-entry. `context` transforms messages, while `agent_end` is notification-only. [Official extension contract](https://github.com/can1357/oh-my-pi/blob/main/docs/extensions.md). | **Not implemented or native-probed**. Pi's installed structured-section API is not assumed for OMP; validate OMP's versioned event result before reuse. |
| Continue CLI / cn | `cn` absent from PATH | Source declares `SessionStart` with `hookSpecificOutput.additionalContext`. Hook configs merge `~/.continue/settings.json`, project `.continue/settings.json`, `.continue/settings.local.json`, and Claude-compatible locations. [Types](https://github.com/continuedev/continue/blob/main/extensions/cli/src/hooks/types.ts), [loader](https://github.com/continuedev/continue/blob/main/extensions/cli/src/hooks/hookConfig.ts). | Native hook candidate exists; **not implemented or native-probed**. Shared Claude locations need duplicate and host-identity checks before any installation. CLI evidence does not establish IDE parity. |
| Crush | `crush` absent from PATH | Current primary hook guide explicitly documents only `PreToolUse`, with JSON stdin/environment and allow/deny output; it is a tool-authorization surface. [Hook guide](https://github.com/charmbracelet/crush/blob/main/docs/hooks/README.md). | **SessionStart/context adapter unsupported by the inspected hook contract**. Do not repurpose permission hooks to inject initialization or grant access. Pin a future supported event before implementation. |
| Amp | `amp` absent from PATH | Default plugin factory receives `PluginAPI`; `amp.on('agent.start',...)` can return a message appended to that turn's user instructions. `session.start` is thread-session initialization. Local `.amp/plugins/` and XDG `amp/plugins/` accept JS/TS entries. [Official plugins](https://ampcode.com/docs/customize/plugins). | Native context candidate exists; **not implemented or native-probed**. `agent.end` continuation could initiate more work and is outside this read-only context adapter scope. |

Presence checks used `shutil.which` for each binary and a filesystem existence check for the conventional Zed app path. Absence from those locations does not prove a machine-wide uninstall. Upstream `main` documentation is a discovery snapshot, not a pinned release acceptance claim.
