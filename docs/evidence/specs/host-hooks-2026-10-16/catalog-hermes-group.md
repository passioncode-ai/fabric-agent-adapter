# Additional host contracts: Hermes research group

Read-only capability survey, 2026-10-16, for the operator's expanded all-Switchboard-host scope. The Switchboard `catalog/agents.json` supplied host IDs and official source roots; its MCP fields are not hook proof. Presence below was computed with `shutil.which` in the task environment. Absent from PATH is not a claim that no IDE extension or installation exists elsewhere. No extra host was installed, authenticated or sent a model request by this module.

## Bounded next work

Prioritize a real Goose discovery fixture because its CLI is present; use context files if the pinned runtime ignores SessionStart output. For the absent CLIs, implementation can be checked against pinned source fixtures, but native acceptance remains unavailable until that host is installed and its parser/loader exercised. Aider and Freebuff need an explicit file-context or custom-agent integration decision; absence of a verified hook API must remain visible rather than receiving a fabricated hook configuration.

All mutable upstream links above were read on 2026-10-16. They establish documented contracts only, not installed behavior. No authentication, provider choice, paid inference, global configuration edit or new background process was performed for these eight rows.
