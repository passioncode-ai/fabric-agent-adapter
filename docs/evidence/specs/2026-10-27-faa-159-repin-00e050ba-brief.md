## Decisions

- D1. The kit's exported functions take the reference's reading (DEC-0141 Status names the three differences the
  readings measured on 0.52.0): `mandateCapability` is read only for `fabric.job.get`, an unusable one is a fault,
  `fabric.job.get` itself is a fault. Before, a job whose tool is not a capability name was covered by an
  `actions`-only mandate; it now waits for the operator at the start and at the answer (CHANGELOG 0.54.0 says so).
- D2. The fault is answered `operator-decision-required`, never `unknown-state`: the contract says the job-step fault
  is answered to the caller as a step the mandate does not cover. Every other fault stays `unknown-state`.
- D3. `make_actions_vectors.mjs` vendors `jobSteps` beside `cases` and re-answers them by the contract's function, so
  a stale copy is caught. Generated against a clean `git archive` of `00e050ba` with its `src/*.ts` imports rewritten
  to `.ts` (Node 26).
- D4. 0.54.0 was stacked on the 0.53.0 branch; 0.53.0 was never published (its release run failed on Windows), so
  0.54.0 is based on `main` after 0.53.1 (`e000c21`) and released after it.
