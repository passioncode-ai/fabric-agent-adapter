# 0.68.0 brief: the exit contract's open steps (FAA-219, FAA-215)

Status: implemented on branch `agent/faa-0.68.0`, 2026-11-05. Serves the board-request dispatch (Fabric 0.3.16, its dispatcher switch stays off on the
operator's machine until FAA-219 ships or Fabric's CO-506 does; board thread `1add3c03`, Fabric `6b165b76`).

## Constraint

The conditional exit contract reaches a Hermes session as one system prompt section, and Hermes caps a plugin's
section at 4000 characters itself (`hermes_cli/plugins_dispatch.py:72`, `MAX_SYSTEM_PROMPT_SECTION_CHARS = 4_000`,
Hermes v0.22.2), so raising `MAX_CONTEXT_CHARS` in the adapter's Hermes plugin buys nothing. 0.67.0 left 2 characters
(3998 at its longest). Every addition below takes its characters back from the contract, moving explanation to
`references/on-demand-session.md`, which the contract names.

## Decisions

- D1 (FAA-219). Step 3: a `com.enroll` refused `not_authorized` takes no slot, asks for no access and does no work.
  When `com.get` reads the request `queued` and `com.status` shows the capability's responder `absent` (a
  `stale` or `held` service responder keeps it queued under the error rule), one `com.reply` (`replyTo` the request, from the target Project, which
  answers it: DEC-0098, DEC-0102) declines it until Fabric ships CO-506 and asks for a resend then (the
  reply ends the queue, so it never says it waits); the workflow closes `done` once
  `com.get` reads it answered, then the retro; any other state is the error rule. On Fabric 0.3.16 a session has no
  route to the grant (`fabric.access.request` is the door's and a binding's, never exposed by `fabric-mcp`; Agent access
  only decides a request already waiting), and work without a slot has no fence. Source: Fabric's answer in thread
  `1add3c03` (option (b), 2026-11-05, to the responder's question `e738ca0f`); the responder's run says the same. A
  first draft of this release had the run do the work and reply with the result (option (a)); the round-1 seam and
  product readings found it unsafe (no fence; a state reply leaves the result owed to nobody) and Fabric chose (b).
- D2 (FAA-215). `observed: true` on a complete after `com.effect_begin` (step 4 in the contract, every such complete in
  the reference), with what it observed (Fabric refuses a complete after an
  effect began without `observed: true`, `observation_required`).
- D3 (FAA-215). Step 6 only once the board accepted the complete (a refused complete is the error rule).
- D4 (FAA-215). Step 7 and the error sentence: the retro follows the error rule too; insight/1 lines go in `insights/`
  as the reference says.
- D5. The characters: name each clause moved to the reference, and keep every test-pinned phrase or move its pin
  with it.
