# Retrospective — FAA-20 part one (0.10.0)

Run stamp: 2026-10-11, PR #57 merged as the 0.10.0 release commit, tag `v0.10.0`.

## Where the run diverged

1. **An independent review found four defects the tests had missed** (logout lost to a concurrent refresh;
   a non-ASCII cookie raised — and crashed the Node sample; NaN disabled the idle bound; a malformed `auth`
   crashed the probe). Surfaced at stage 5 review; owned by stage 4/5 (the plan named no concurrency or
   hostile-input cases). Root cause: the test list was derived from the contract's four ends, not from the
   attacker's inputs. Fixed in the same PR, each with a regression test that failed first.
   **Next time:** a session or credential check gets three test rows by default — concurrent writers,
   non-ASCII/oversized input, non-finite configuration.
2. **The pin-drift check rejected hex-looking names three times** (`dec0039` in a branch and a spec name, an
   old pin in a backlog row). Not a defect in the check: any 7+ hex run beside "contract" reads as a revision.
   **Next time:** name branches and files without `dec00NN`-style tokens; refer to merges by PR number.
3. **A peer session's cleanup removed this run's scratch contract checkouts** mid-run, so a schema-arm run
   reported NOT_RUN. Detected by reading the receipt (`contract checkout is not a directory`), not the count.
   **Next time:** keep scratch checkouts under a name no other repository's cleanup pattern matches.
