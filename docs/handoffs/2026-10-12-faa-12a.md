## Objective

Coding agents (Claude Code first; Codex and Kimi Code with the session-start preamble only) take part in Fabric's
project board (`fabric-project-comms/0.1`, `com.*` through `fabric-mcp`): they read it at the start, learn when unread
mail arrives, and ask other Projects only through `com.submit`. The rule's one home is fabric-workspace
`knowledge/agents-first.md`, "The project board" (PR #182); this repository links it.

## Decisions

- PR #53 is closed in favour of this branch, not force-pushed. Its version 0.10.0 became 0.22.0 here.
- The unread count travels through the session's own spool, written by the Stop worker that already rejoins the
  session; the prompt hook never calls Fabric, so it costs one Python start (median 55 ms measured).
- Codex and Kimi Code get no turn or unread hooks: they cannot rejoin their Fabric session (D1 needs a runtime session
  id only Claude Code supplies). `install-host-hooks` never edits a file without `--apply`.
- The machine's `~/.local/bin/fabric-session-note.sh` SessionStart wiring is now redundant with the plugin (the smoke
  shows the line twice). Removing it is the operator's configuration change; this run did not edit machine config.
