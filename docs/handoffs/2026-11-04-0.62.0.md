# 0.62.0: a new install names its repository, and a service says what it uses

Branch `agent/faa-0.62.0`, on main `1119308` (0.61.0).

## Objective

deadline 2026-11-11): FAA-198 (`source.repository` required for a new install) and FAA-199 (connections declared

## Decisions

- A missing `source.repository` and a missing connections declaration are `NOT_RUN` in the probe, never `FAIL`: an
  installed agent keeps passing its other rules until its owner adds them, and `NOT_RUN` is never a pass.
- The sample's default repository is this repository, where the sample is built from.
