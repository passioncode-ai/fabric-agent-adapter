# 0.62.0: a new install names its repository, and a service says what it uses

Branch `agent/faa-0.62.0`, on main `1119308` (0.61.0).

## Objective

Release 0.62.0 for Project Observatory's agent map (board thread `bde4737e`, capability `agent-map.descriptors`,
deadline 2026-11-11): FAA-198 (`source.repository` required for a new install) and FAA-199 (connections declared
through the kit). No owner field is added to the descriptor.

## Done

- FAA-198: `write_descriptor` / `writeDescriptor` refuse a new descriptor without `source.repository`;
  `register_remote` / `registerRemote` refuse it before the token file is written; a rewrite of an installed descriptor
  without it warns (`warnings.warn`; Node `process.emitWarning`, code `FABRIC_NO_SOURCE_REPOSITORY`);
  `source_refusal` / `sourceRefusal`; `check_service.py` rule `descriptor.source-repository` (`NOT_RUN` when absent);
  `sample_service.py register --repository` (the sample's own repository by default). Tests:
  `DescriptorTests.test_a_new_install_names_its_repository_and_a_reinstall_without_it_warns`,
  `test_the_probe_names_a_missing_repository`, the Node twin `a new install names its repository; a reinstall without
  it warns (FAA-198)`, the sample's `--repository` in `test_the_sample_writes_the_object_form`, and the refused remote
  registrations in `test_register_remote_source` and its Node twin (no token file left).
- FAA-199: the reference service declares `extensions/connections/0.1` (its template model and its demo source);
  `SupportAgent.connections()` in the support-agent recipe; `check_service.py` reports `well-known.connections`
  `NOT_RUN` when none is declared; adapting-projects-to-fabric's adapter step names both declarations; scenario eval
  `service-names-its-repository-and-connections`. Tests: `test_the_sample_declares_what_it_uses`,
  `test_it_declares_its_models_as_connections`, `test_connections_fac_sem_127`.
- The 12 descriptors the board thread lists (of 34 on one machine, 2026-11-04): read with `source_refusal` against the
  machine's services directory, every one is a rewrite that warns, none is refused (the names stay on the board, this
  repository is public).

## Decisions

- A missing `source.repository` and a missing connections declaration are `NOT_RUN` in the probe, never `FAIL`: an
  installed agent keeps passing its other rules until its owner adds them, and `NOT_RUN` is never a pass.
- The sample's default repository is this repository, where the sample is built from.
