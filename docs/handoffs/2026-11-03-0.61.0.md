## Decisions

- Reading is opt-in: the kit cannot tell the operator's personal board from an organization's (`com.status` names
  neither, read 2026-11-03), so the service names the sender Projects it trusts, or `PERSONAL_BOARD`. Default: none.
- No `callerAgent`: the board names a Project's principal, not an authenticated agent id, so the chain's end alone
  binds the mandate (MD-3).
- The handler records `recordAs`; the kit puts the operator's words in no event, log or checkpoint.
