## For consumers

A project that runs this checkout's `check_service.py` in its own tests now needs the socket table (`sysctl` or
`netstat` and `ps` on macOS, `/proc` on Linux): a sandbox that denies them, or a service behind a root-owned port
forward, reads `listener.owner` FAIL. Vendored copies get `fabric_peer_owner` through `fabric_kit.py install`.
